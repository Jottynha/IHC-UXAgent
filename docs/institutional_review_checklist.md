# Checklist para aprovação institucional

Este documento prepara a submissão; não representa aprovação concedida.

- [ ] Identificar instituição, responsável e orientador.
- [ ] Anexar objetivo, pergunta de pesquisa e justificativa.
- [ ] Anexar [human_validation_protocol_v1.md](human_validation_protocol_v1.md).
- [ ] Confirmar população adulta, critérios de inclusão e exclusão.
- [ ] Revisar recrutamento, compensação e liberdade de retirada.
- [ ] Preparar termo de consentimento informado.
- [ ] Definir pseudonimização, armazenamento, acesso e prazo de eliminação.
- [ ] Confirmar que nenhum diagnóstico ou dado sensível desnecessário será coletado.
- [ ] Informar que T1/T2 sintéticas não representam participantes humanos.
- [ ] Informar que T3/T4 são reservadas e não calibram o agente.
- [ ] Submeter ao comitê ou instância institucional competente.
- [ ] Aguardar aprovação formal antes de recrutar ou coletar dados.

Até a conclusão desta lista e aprovação documentada, a validação humana está
bloqueada.
